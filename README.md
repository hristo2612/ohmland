# Ohmland

Learn electronics from zero, right in your browser. No parts, no soldering iron, no risk.

Ohmland is a free, open-source course with hands-on virtual labs: plug parts into a 3D breadboard, measure them with a
multimeter, watch LEDs glow (and burn out), charge capacitors, switch relays and transistors. A real circuit simulator
runs every lab. As you learn, your own floating circuit-board island grows, one component at a time.

Status: early development.

## Development

```bash
pnpm install
pnpm dev
```

Requires Node 22.12 or newer (Node 24 recommended) and pnpm 10.
